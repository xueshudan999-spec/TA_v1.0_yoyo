程序化故障艺术Glitch渲染
1. 项目概述
项目目标：基于Unity的一套程序化的故障特效Shader。用于赛博朋克场景的氛围表现。
核心特性：
模型顶点沿着法线方向发生随机偏移。
节奏化控制：利用时间变量实现“间歇性爆发”的动画节奏，而非无脑持续闪烁。
视角渐变：基于摄像机空间法线的双色渐变与菲涅尔边缘融合。

2. 核心渲染逻辑拆解
该Shader包含一个基础的Pass，在顶点着色器和片元着色器中均进行了数学计算。

2.1 程序化噪波生成
为了生成无序的故障纹理，代码自定义了GlitchNoise(float2 coord)函数：
利用for循环，结合floor取整、sin正弦函数以及随时间变化的_Time变量。
通过c*= 2.5逐级放大坐标，生成具有高度复杂性和伪随机性的多维噪波数据。该噪波同时用于顶点的位移和像素颜色的干扰。

2.2 顶点动画
在vert函数中，实现了模型表面的炸裂/拉扯效果：
动态遮罩：通过GetMask函数，利用正弦/余弦对UV进行随时间波动的缩放，采样_Mask贴图，控制发生故障的区域。
时间分片与节奏控制（核心亮点）：

    float phase = frac(_Time.y / 4);
    float active = step(phase, 0.5);       
    float localPhase = phase * 2.0;         
    float animWeight = active * sin(localPhase * 6.28318);

通过计算时间相位，将4秒作为一个周期。前0.5激活特效，后0.5停止，配合正弦曲线实现平滑的“动-停-动”间歇爆发感。
顶点偏移：将噪波值、遮罩、方向向量（_X, _Y, _Z）、世界空间法线以及动画权重相乘，最终作用于顶点坐标，实现带有方向性的物理膨胀。

2.3 像素级信号干扰
在 frag 函数中，模拟了老式电视或数据损坏的视觉特征：
UV 扭曲：结合滚动的噪声图和遮罩，计算distortUV，使画面产生波形拉伸。
RGB通道分离：再次调用GlitchNoise，利用时间正弦函数不同频率speedtime, speedtime*2, speedtime*3，将噪波的XYZ分量分别累加到最终颜色的R、G、B通道上，模拟红绿蓝色彩错位的故障感。

2.4 视角渐变与边缘融合
摄像机空间渐变：如果开启EnableCol，则利用摄像机空间法线的X分量，在_Dir1Col和_Dir2Col之间进行线性插值，产生类似全息投影的随视角变色效果。否则，利用世界坐标X生成HSV随机色。
菲涅尔遮罩：计算视线向量V与法线的点乘，结合Fresnel_Scale和Fresnel_Power计算边缘光强。最终将原贴图BaseMap与故障色glitchColor进行lerp，确保故障效果主要集中在模型边缘，保留中心的清晰度。
